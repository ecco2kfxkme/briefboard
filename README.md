# Briefboard

Компактная производственная kanban-доска для небольших продуктовых и креативных команд.

## Возможности

- четыре этапа и перенос карточек drag-and-drop;
- смена статуса с клавиатуры через select;
- поиск и фильтр приоритета;
- создание и редактирование в отдельных рабочих панелях;
- сроки, просрочка, видимый текст приоритета;
- удаление с отменой;
- импорт и экспорт JSON;
- локальное сохранение без регистрации.

Сделано на чистых HTML, CSS и JavaScript.
