# Briefboard

Локальная kanban-доска для продуктовых и контентных задач. Работает без регистрации, сервера и сборки.

## Возможности

- четыре этапа и drag-and-drop;
- поиск и фильтр приоритета;
- сроки, статистика и прогресс;
- импорт и экспорт JSON;
- светлая и тёмная темы;
- сохранение данных в `localStorage`;
- адаптивная вёрстка и доступное управление этапами через `select`.

## Запуск

Откройте `index.html` в браузере. Стек: HTML, CSS, JavaScript без зависимостей.
